Published WordPress.org Plugins

Nov 2015 – Dec 2015

Authored and published six WordPress plugins to the public wordpress.org plugin directory under a GPLv2 license.

Six WordPress plugins, each maintained in its own SVN checkout with trunk/tags/branches under Contributors: larjen (GPLv2):

  • WPTweetImporter – imports a user's tweets as WordPress posts via the Twitter API, with scheduled automation and optional hashtag sanitization.
  • WPRestApiExtensions – custom read-only REST endpoints for posts/tags with an optional file-system cache and JSONP support for AngularJS clients.
  • WPMarkdownImporter – bulk-imports Markdown files as posts, bundling Parsedown 1.6.0.
  • WPRestCache – a file-based cache in front of the WordPress REST API with auto-wipe on content change.
  • WPTagSanitizer – normalizes post tags via an editable JSON dictionary.
  • WPToggler – a global boolean option exposed via shortcode and a template API for theme developers.

Consistent architecture across all six: a bootstrap file, includes/main.php, includes/admin.php settings screen, and a WordPress-format readme.txt.
